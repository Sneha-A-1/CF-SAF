## Dataset 1 — NASA SMAP Level-3 Enhanced Passive Soil Moisture

| Field | Detail |
|---|---|
| **Product** | SMAP Enhanced L3 Radiometer Global Daily 9 km EASE-Grid Soil Moisture |
| **Version** | 6 (SPL3SMP_E.006) |
| **DOI** | https://doi.org/10.5067/M20OXIZHY3RJ |
| **Access** | NASA AppEEARS: https://appeears.earthdatacloud.nasa.gov |
| **Account required** | Free NASA Earthdata Login |

### How to download
1. Register at https://urs.earthdata.nasa.gov
2. Go to https://appeears.earthdatacloud.nasa.gov
3. Submit a new Area/Point sample request
4. Select product: **SPL3SMP_E.006**
5. Select layers:
   - `Soil_Moisture_Retrieval_Data_AM_soil_moisture`
   - `Soil_Moisture_Retrieval_Data_PM_soil_moisture_pm`
   - `Soil_Moisture_Retrieval_Data_AM_retrieval_qual_flag_scav`
   - `Soil_Moisture_Retrieval_Data_AM_surface_temperature`
   - `Soil_Moisture_Retrieval_Data_AM_vegetation_water_content`
6. Set AOI polygon (Uttarakhand, India):
   `[77.55,30.0] → [80.6,30.0] → [80.6,31.5] → [77.55,31.5]`
7. Set date range: **2022-10-01 to 2024-10-31**

### Bands downloaded
SR_B3 (Green), SR_B4 (Red), SR_B5 (NIR), SR_B6 (SWIR-1),
QA_PIXEL, MTL.txt

### Spectral indices computed
- NDVI = (B5 - B4) / (B5 + B4)
- NDWI = (B3 - B5) / (B3 + B5)
- Moisture Index (MI) = (B5 - B6) / (B5 + B6)
- EVI = 2.5 × (B5 - B4) / (B5 + 6×B4 - 7.5×B2 + 1)

### Note on seasons 2–9
Only Season 1 (October 2022) was directly downloaded from USGS.
Seasons 2–9 were synthetically generated by sampling from the
statistical distributions observed in Season 1, as described
in Section III of the paper. The generation script is at
`data/synthetic/generate_dataset.py`.

## Dataset 3 — Farm-Flow AG-IoT Security Dataset

| Field | Detail |
|---|---|
| **Dataset** | Farm-Flow: AG-IoT Security Intrusion Detection in Smart Agriculture |
| **DOI** | https://doi.org/10.5281/zenodo.10964648 |
| **Access** | Zenodo (no login required): https://zenodo.org/record/10964648 |
| **Size** | 532 MB compressed |
| **Instances** | 1,310,000 network flow records |

### Role in this paper
The Farm-Flow dataset is used **only for scheduling workload simulation**
(task arrival rate distributions and flow duration statistics for HAPSA/ORSA-F
evaluation). The 27,458 normal traffic instances were used to extract
empirical task inter-arrival times, flow durations, and payload size
distributions. Attack instances were excluded from workload modelling.
