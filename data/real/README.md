# Real farm data (Belli et al., 2025)

Download these three files from Mendeley Data, doi:10.17632/35wh56287y.2
(https://data.mendeley.com/datasets/35wh56287y/2), and place them in this folder:

- stuard_environmental_data.csv
- stuard_soil_data.csv
- stuard_water_meter_data.csv

Reference: L. Belli et al., "Smart agriculture dataset in a tomato cultivation under
different irrigation regimes," Data in Brief, vol. 60, 111521, 2025.
